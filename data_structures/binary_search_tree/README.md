# Binary Search Tree

This subproject contains the scaffold for a generic binary search tree.

The public interface is declared in `include/binary_search_tree.hpp` and is
intentionally not implemented yet. As a class template, its member definitions
should be added in the header (or in a header included from it).

The planned interface supports insertion, lookup, removal, clearing, and an
in-order traversal. Tests belong in `tests/` and should be added as each
operation is implemented.
